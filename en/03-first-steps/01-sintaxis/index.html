    Sintaxis básica

    This content is not available in your language yet.

    La sintaxis de Python está diseñada para ser sencilla y legible. A diferencia de otros lenguajes, Python utiliza la indentación para estructurar el código y utiliza palabras reservadas y símbolos con reglas bien definidas.

    Comentarios

    Sección titulada «Comentarios»

    Consejo

    Utiliza # para comentarios breves dentro del código y docstrings para documentar módulos, funciones, clases y métodos.

    Indentación y bloques

    Sección titulada «Indentación y bloques»

    Python utiliza la indentación para definir la estructura de los bloques de código. A diferencia de lenguajes que utilizan llaves ({}) para delimitar bloques, en Python la indentación forma parte de la sintaxis; se usan espacios o tabuladores de forma consistente.

    Cada nivel de anidamiento debe usar el mismo número de espacios (se recomienda 4).

    Las estructuras como if, for, while, def y class terminan en dos puntos : y su cuerpo va indentado.

    Cada nivel de anidamiento debe mantener una indentación consistente. La recomendación habitual es utilizar 4 espacios por nivel.

    Precaución

    No mezcles espacios y tabuladores para crear niveles de indentación. Aunque Python puede detectar algunas inconsistencias, hacerlo puede provocar errores difíciles de identificar.

    Resumen

    Sección titulada «Resumen»

    Los elementos fundamentales de la sintaxis de Python son:

    • # permite escribir comentarios de una línea.
    • Los docstrings documentan módulos, funciones, clases y métodos.
    • La indentación define los bloques de código.
    • Los : introducen bloques en estructuras como if, for, while, def y class.
    • Las expresiones producen valores.
    • Las sentencias realizan acciones.
    • print() muestra información.
    • input() recibe texto del usuario.
    • import permite utilizar módulos y paquetes.
    • Python distingue entre mayúsculas y minúsculas.
    • snake_case, PascalCase y UPPER_SNAKE_CASE son convenciones habituales para nombrar elementos.

    Dominar estos conceptos proporciona la base necesaria para comprender estructuras de control, funciones, clases y módulos.

    Las palabras se separan mediante guiones bajos (_) y normalmente se escriben en minúsculas.

    Para que el código sea legible y mantenible:

    • Nombres de variables y funciones: snake_case (por ejemplo, mi_variable)
    • Clases: PascalCase (por ejemplo, MiClase)
    • Constantes: UPPER_SNAKE_CASE (por ejemplo, PI = 3.14)
