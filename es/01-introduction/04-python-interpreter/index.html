El intérprete de Python

El intérprete de Python es el programa responsable de leer, analizar y ejecutar código Python. Cada vez que ejecutas un programa escrito en Python, es el intérprete quien transforma las instrucciones del código fuente en acciones que el sistema operativo puede realizar 1.

Aunque muchas personas lo asocian únicamente con la consola interactiva, el intérprete puede ejecutar código de distintas maneras: desde un archivo, una instrucción escrita directamente en la terminal o en el modo interactivo.

Intérprete ≠ REPL

REPL (Read–Eval–Print Loop) es uno de los modos de funcionamiento del intérprete, pero no el único.

Formas de ejecutar código

Sección titulada «Formas de ejecutar código»

El intérprete admite diferentes formas de ejecución según la tarea que se quiera realizar.

Modo interactivo (REPL)

Sección titulada «Modo interactivo (REPL)»

Permite escribir instrucciones una por una y obtener el resultado inmediatamente. Para entrar en este modo, abre la terminal y ejecuta python o python -q (para salir ejecuta quit(), exit() o un atajo de teclado como los detallados en la siguiente sección).

Ejecutar un script

Sección titulada «Ejecutar un script»

La forma más habitual de trabajar consiste en escribir el código en un archivo con extensión .py y que el intérprete lo ejecute.

  • Directorio.venv/
    • …
  • .env
  • .gitignore
  • .python-version
  • README.md
  • main.py
  • pyproject.toml
  • uv.lock

Este modo es el recomendado para desarrollar programas completos.

Ejecutar una instrucción

Sección titulada «Ejecutar una instrucción»

Si solo se necesita ejecutar una instrucción sencilla desde la terminal, se puede utilizar la opción -c (command, comando).

Esta opción es muy utilizada en scripts de automatización y pruebas rápidas. 2

Ejecutar un módulo

Sección titulada «Ejecutar un módulo»

También es posible ejecutar un módulo instalado utilizando la opción -m (module, módulo).

En este caso el intérprete busca el módulo indicado y lo ejecuta como si fuera un programa.

El modo interactivo (REPL)

Sección titulada «El modo interactivo (REPL)»

Cuando el intérprete se inicia sin indicar un archivo ni una instrucción, entra automáticamente en modo interactivo, también conocido como REPL (Read Eval Print Loop).

En este modo, permite ejecutar instrucciones línea por línea y obtener el resultado de forma inmediata.

¿Cuándo usar el modo interactivo?

Es útil para probar, experimentar y/o verificar fragmentos de código sin necesidad de crear un archivo .py.

¿Qué significa REPL?

Sección titulada «¿Qué significa REPL?»

El acrónimo REPL describe el ciclo de funcionamiento del intérprete (este proceso ocurre continuamente hasta que se cierre el intérprete):

Read (leer)

Recibe la instrucción.

Eval (evaluar)

Ejecuta la instrucción.

Print (imprimir)

Muestra el resultado.

Loop (repetir)

Espera la siguiente instrucción.

Iniciar el modo interactivo

Sección titulada «Iniciar el modo interactivo»

Abrir una terminal y ejecutar:

  • Windows
  • macOS
  • Linux

También puedes iniciar el intérprete con el parámetro -q:

  • Windows
  • macOS
  • Linux

Consejo

El parámetro -q (quiet, silencioso) evita mostrar el mensaje de bienvenida y la información de versión.

Los prompts

Sección titulada «Los prompts»

Durante el modo interactivo aparecen dos indicadores (prompts).

IndicadorDescripción
Prompt primario (>>>)El intérprete está listo para recibir una nueva instrucción.
Prompt secundario (...)El bloque de código aún no ha terminado y el intérprete espera más líneas.

Salir del modo interactivo

Sección titulada «Salir del modo interactivo»

Puedes salir el modo interactivo de las siguientes formas:

  • Escribiendo quit() o exit().

  • O presionando el atajo correspondiente para el carácter EOF (end of file, fin de archivo 3) en tu sistema operativo:

    • Windows
    • macOS
    • Linux

    Ctrl + Z, luego Enter

    Ctrl + D

    Ctrl + D
